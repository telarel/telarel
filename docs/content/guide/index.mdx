Telarel is an extensible JavaScript compiler written in Rust, and built around plugin hooks.

The compiler exposes five entry points — `parse`, `rewrite`, `generate`, `compileFromAst`, and `compile`. Each takes its source (text or an owned AST), an options value, and a list of plugins, and returns an AST result or a code result with an optional source map.

Read the [Getting Started](/guide/getting-started) guide to install Telarel and run your first compile.
