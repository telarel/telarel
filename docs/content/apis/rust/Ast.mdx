title: Ast
description: An owned AST with its source text, language metadata, input source map, and mutable program access.

`Ast` holds an oxc `Program`, the source text its spans anchor to, language metadata derived from that program, and an optional input source map.

```rust
pub struct Ast { /* private fields */ }

impl Ast {
    pub fn from_source<F>(
        source: Arc<str>,
        language: Language,
        source_type: SourceType,
        input_map: Option<SourceMap>,
        build: F,
    ) -> Ast
    where
        F: for<'a> FnOnce(&'a str, &'a Allocator) -> Program<'a>;

    pub fn try_from_source<F, E>(
        source: Arc<str>,
        language: Language,
        source_type: SourceType,
        input_map: Option<SourceMap>,
        build: F,
    ) -> Result<Ast, E>
    where
        F: for<'a> FnOnce(&'a str, &'a Allocator) -> Result<Program<'a>, E>;

    pub fn program(&self) -> &Program<'_>;
    pub fn source(&self) -> &Arc<str>;
    pub fn language(&self) -> Language;
    pub fn source_type(&self) -> SourceType;
    pub fn map(&self) -> Option<&SourceMap>;

    pub fn with_input_map(&self, map: Option<SourceMap>) -> Ast;

    pub fn with_mut<R>(
        &mut self,
        f: impl for<'i> FnOnce(&'i Allocator, &mut Program<'i>) -> R,
    ) -> R;
}
```

## Construction

`parse` is the normal way to obtain an `Ast`. `from_source` and `try_from_source` are lower-level constructors that build an `Ast` from an existing oxc `Program`. The closure receives the source text and the allocator that the program must borrow. The closure must return a program whose `source_text` is that source.

## Accessors

| Accessor            | Type                 | Description                                                                        |
| ------------------- | -------------------- | ---------------------------------------------------------------------------------- |
| `ast.program()`     | `&Program<'_>`       | The parsed program.                                                                |
| `ast.source()`      | `&Arc<str>`          | The source text the program's spans anchor to.                                     |
| `ast.language()`    | `Language`           | The grammar of the parsed program: `JS`, `TS`, `DTS`, `JSX`, or `TSX`.             |
| `ast.source_type()` | `SourceType`         | The resolved module kind of the parsed program: `Script`, `CommonJS`, or `Module`. |
| `ast.map()`         | `Option<&SourceMap>` | The input source map, if any.                                                      |

`Language` and `SourceType` are the Telarel enums. `source_type()` never reports `Unambiguous` for a normally parsed AST. `Unambiguous` is a parser input. A parsed program resolves to `Script`, `CommonJS`, or `Module`.

Program spans are UTF-8 byte offsets into `source()`, matching `oxc::span::Span`.

## Input source map

`ast.map()` is the **input** source map. It describes how this AST's source was produced from upstream originals. It is not the source map generated from this AST.

`with_input_map` rebuilds the AST with a different input source map. It clones the program into a fresh allocator. It shares the source text.

## Mutation

`with_mut` is the only path to the arena. The closure receives the allocator and a mutable program. The closure can allocate new nodes while it mutates.

The closure may rewrite the tree but cannot change the source text. `Program::source_text` must stay content-equal to `Ast::source`. Debug builds assert this. To change the source text, build a new `Ast`.

`Ast` clones are O(1). They share the same arena. When another clone is still alive, `with_mut` copies the arena first. Mutating a clone never mutates the original.

Only the `transform` hook lets its mutations reach later stages. The `prepare`, `finalize`, and `generate` hooks receive a borrowed `&Ast`. They cannot mutate the program through `with_mut`.

## Thread safety

`Ast` is `Send + Sync`. Plugin futures can move owned handles or borrow the AST across threads. Sharing `&Ast` across threads is read-only. `Program` exposes interior-mutable `Cell` fields. Mutating them through a shared `&Ast` is a data race and is forbidden.

## Example

```rust
use telarel::allocator::Allocator;
use telarel::ast::ast::Program;
use telarel::{parse, Ast, ParseOptions, AstResult};

let parsed: AstResult = parse(
    String::from("const x: number = 1;"),
    ParseOptions::default(),
    vec![],
).await?;

let mut ast: Ast = parsed.ast;

ast.with_mut(|_: &Allocator, program: &mut Program<'_>| {
    program.body.clear();
});

assert!(ast.program().body.is_empty());
```
