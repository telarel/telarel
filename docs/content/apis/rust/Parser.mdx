```rust
pub struct Parser { /* private fields */ }

impl Parser {
    pub fn new(code: String, options: ResolvedParserOptions) -> Self;

    pub fn parse(self) -> Result<AstResult, CompileError>;
}
```

The pipeline uses `Parser` as the builtin parser and terminal fallback after every `parse` hook defers. It never runs the plugin chain. When plugins should be able to replace the parse result, use [`parse`](/apis/rust/parse).

## `Parser::new`

Creates a parser over `code` and its resolved `ResolvedParserOptions`.

### `ResolvedParserOptions`

Every field is required. This is the resolved type. To request the values, set the `parser` group on `ParseOptions` or `CompileOptions`, or return it from an `options` hook. In a `parse` hook, the same value is available as `args.options`.

| Field                           | Type               | Description                                                             |
| ------------------------------- | ------------------ | ----------------------------------------------------------------------- |
| `cwd`                           | `PathBuf`          | Working directory used to resolve `file` and a relative input-map path. |
| `file`                          | `String`           | The file being parsed.                                                  |
| `language`                      | `Language`         | The grammar of the code.                                                |
| `source_type`                   | `SourceType`       | The module system of the code.                                          |
| `source_map`                    | `SourceMapOptions` | Source-map request for the step.                                        |
| `preserve_parens`               | `bool`             | Whether parenthesized expressions stay in the AST.                      |
| `allow_return_outside_function` | `bool`             | Whether `return` is accepted outside a function body.                   |
| `oxc`                           | `OxcParseOptions`  | The full effective options for the raw oxc parser.                      |

`cwd` anchors resolution of `file`. A relative input-map `path` resolves against the source file's directory; absolute paths are used as-is.

`oxc` is the full effective object after the three [option layers](/apis#option-layering) apply. It is not the requested partial patch. See [parser options](/apis#parser-options).

## `Parser::parse`

Parses the fixed source text and returns the resulting AST. The parser resolves a requested input source map and attaches it to the returned AST. The pipeline applies the resolved output source-map mode.

`AstResult` is `{ ast: Ast }`. See [Ast](/apis/rust/Ast) for accessors, clone semantics, and mutation.

## Example

```rust
use std::path::PathBuf;

use telarel::{
    AstResult, Language, Parser, ResolvedParserOptions,
    ResolvedParserStageOptions, SourceMapOptions, SourceType,
};

let parser: Parser = Parser::new(
    String::from("const x: number = 1;"),
    ResolvedParserOptions {
        cwd: PathBuf::from("."),
        file: String::from("index.ts"),
        language: Language::TS,
        source_type: SourceType::Module,
        source_map: SourceMapOptions::default(),
        preserve_parens: false,
        allow_return_outside_function: false,
        oxc: ResolvedParserStageOptions::default().oxc,
    },
);

let result: AstResult = parser.parse()?;
```
