```rust
pub struct Parser { /* private fields */ }

impl Parser {
    pub fn new(code: String, options: ParserOptions) -> Self;

    pub fn parse(self) -> Result<AstResult, CompileError>;
}
```

The pipeline uses `Parser` as the builtin parser and terminal fallback after every `parse` hook defers. It never runs the plugin chain. When plugins should be able to replace the parse result, use [`parse`](/apis/rust/parse).

## `Parser::new`

Creates a parser over `code` and its resolved `ParserOptions`.

### `ParserOptions`

Every field is required. In a `parse` hook, the stage options are available as `args.options`.

| Field         | Type               | Description                                                                                                                                                            |
| ------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cwd`         | `PathBuf`          | Filesystem root used to locate the source file. A relative `path` in the input source map resolves against the source file's directory. Absolute paths are used as-is. |
| `file`        | `String`           | The file being parsed.                                                                                                                                                 |
| `language`    | `Language`         | The grammar of the code.                                                                                                                                               |
| `source_type` | `SourceType`       | The module system of the code.                                                                                                                                         |
| `source_map`  | `SourceMapOptions` | The source-map inputs and outputs requested for the step.                                                                                                              |

## `Parser::parse`

Parses the fixed source text and returns the resulting AST. The parser resolves a requested input source map and attaches it to the returned AST. The pipeline applies the resolved output source-map mode.

`AstResult` is `{ ast: Ast }`. See [Ast](/apis/rust/Ast) for accessors, clone semantics, and mutation.

## Example

```rust
use std::path::PathBuf;

use telarel::{
    AstResult, Language, Parser, ParserOptions, SourceMapOptions, SourceType,
};

let parser: Parser = Parser::new(
    String::from("const x: number = 1;"),
    ParserOptions {
        cwd: PathBuf::from("."),
        file: String::from("index.ts"),
        language: Language::TS,
        source_type: SourceType::Module,
        source_map: SourceMapOptions::default(),
    },
);

let result: AstResult = parser.parse()?;
```
