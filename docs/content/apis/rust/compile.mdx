title: compile
description: Compile source text from parse to generate.
---

```rust
pub async fn compile(
    code: String,
    options: CompileOptions,
    plugins: Vec<SharedPluginable>,
) -> Result<CodeResult, CompileError>
```

Compiles `code` from source to generated output.

Because the stages run inline, the pipeline invokes each stage once per invocation. The hooks follow the shared [hook semantics](/apis/plugin#hook-semantics). The `options` hook runs once per plugin instance. The `start` and `end` hooks run per settled entry.

An explicit input source-map request wins over the AST's own input map when it resolves to a map. If the request is `Inline` or `Auto` and finds no map, the AST's own map is kept. An `External` request that cannot read its map rejects. The pipeline applies the request to the AST that the winning `parse` hook returns. The builtin parser is the fallback when every `parse` hook defers.

The request applies to the AST at the entry boundary. A map returned by a transform hook is the downstream result and is not replaced by the request.

## Parameters

| Name      | Type                    | Description                 |
| --------- | ----------------------- | --------------------------- |
| `code`    | `String`                | The source text to compile. |
| `options` | `CompileOptions`        | The compile options.        |
| `plugins` | `Vec<SharedPluginable>` | The plugins to run.         |

### `CompileOptions`

Every field is optional. The pipeline resolves each field against defaults before use.

| Field         | Type                       | Default             | Description                                                                  |
| ------------- | -------------------------- | ------------------- | ---------------------------------------------------------------------------- |
| `cwd`         | `Option<PathBuf>`          | process working dir | Filesystem root used to resolve relative paths.                              |
| `file`        | `Option<String>`           | `index.ts`          | The file being compiled. The language is inferred from its extension.        |
| `language`    | `Option<Language>`         | inferred            | The grammar of the code. Overrides the extension inference.                  |
| `source_type` | `Option<SourceType>`       | inferred            | The module system of the code. Overrides the grammar's module kind.          |
| `output`      | `Option<OutputOptions>`    | `file`              | Output code configuration. `output.file` derives the default source-map URL. |
| `source_map`  | `Option<SourceMapOptions>` | off                 | The source-map inputs and outputs requested for the run.                     |

## Returns

`Result<CodeResult, CompileError>`, where `CodeResult` is `{ code: String, map: Option<SourceMap> }`.

## Example

```rust
use telarel::{compile, CompileOptions, CodeResult};

let result: CodeResult = compile(
    String::from("const x: number = 1;"),
    CompileOptions::default(),
    vec![],
).await?;

println!("{}", result.code); // const x: number = 1;
```
