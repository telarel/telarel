---
title: rewrite
description: Rewrite an AST with plugins.
---

```rust
pub async fn rewrite(
    ast: Ast,
    options: RewriteOptions,
    plugins: Vec<SharedPluginable>,
) -> Result<AstResult, CompileError>
```

Rewrites `ast` through the plugin chain. An empty plugin list runs no transform hooks. The pipeline returns the AST without modification.

An AST's own input source map wins. When the AST carries none, the pipeline attaches the requested input source map before the stages run.

## Parameters

| Name      | Type                    | Description          |
| --------- | ----------------------- | -------------------- |
| `ast`     | `Ast`                   | The AST to rewrite.  |
| `options` | `RewriteOptions`        | The rewrite options. |
| `plugins` | `Vec<SharedPluginable>` | The plugins to run.  |

### `RewriteOptions`

Every field is optional. The pipeline resolves each field against defaults before use.

| Field              | Type                     | Default                    | Description                                                           |
| ------------------ | ------------------------ | -------------------------- | --------------------------------------------------------------------- |
| `cwd`              | `Option<PathBuf>`        | process working dir        | Filesystem root used to resolve relative paths.                       |
| `file`             | `Option<String>`         | `index.ts`                 | The file being rewritten. It supplies option and source-map defaults. |
| `language`         | `Option<Language>`       | AST language               | The grammar recorded in the resolved options.                         |
| `source_type`      | `Option<SourceType>`     | AST module kind, then file | The module kind recorded in the resolved options.                     |
| `input_source_map` | `Option<InputSourceMap>` | off                        | The input source-map request for the step.                            |

The explicit values are visible to the `options` hook. After resolution, the explicit or inferred values are visible to `start` and later hooks through the resolved options and `PluginContext.module`.

The grammar comes from `language` when set, then the input AST. The module kind comes from a concrete `source_type`, then the AST module kind, then the file extension. `Unambiguous` requests inference. A concrete `source_type` replaces the input AST module kind before the stages run.

`rewrite` does not reparse the input AST. The returned AST is the input AST, or a plugin replacement with its own module kind.

`rewrite` produces an AST, so it has no output source map. The shared plugin options bag presents this request as `source_map.input`. `rewrite` ignores a plugin-set `source_map.output` or top-level `output`.

## Returns

`Result<AstResult, CompileError>`, where `AstResult` is `{ ast: Ast }`. See [Ast](/apis/rust/Ast).

## Example

```rust
use telarel::{
    parse,
    rewrite,
    ParseOptions,
    RewriteOptions,
    AstResult,
};

let parsed: AstResult = parse(
    String::from("const x: number = 1;"),
    ParseOptions::default(),
    vec![],
).await?;

let rewritten: AstResult = rewrite(parsed.ast, RewriteOptions::default(), vec![]).await?;
```
