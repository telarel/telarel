---
title: Generator
description: A builtin generator over a borrowed AST and fixed options.
---

```rust
pub struct Generator<'a> { /* private fields */ }

impl<'a> Generator<'a> {
    pub fn new(ast: &'a Ast, options: GeneratorOptions) -> Self;

    pub fn generate(self) -> Result<CodeResult, CompileError>;
}
```

The pipeline uses `Generator` as the builtin generator and terminal fallback after every `generate` hook defers. It never runs the plugin chain. When plugins should be able to replace the generated result, use [`generate`](/apis/rust/generate).

## `Generator::new`

Creates a generator over `ast` and its resolved `GeneratorOptions`.

`Generator::new` borrows the AST because hook arguments are read-only.

### `GeneratorOptions`

Every field is required. In a `generate` hook, the stage options are available as `args.options`.

| Field        | Type               | Description                                                 |
| ------------ | ------------------ | ----------------------------------------------------------- |
| `cwd`        | `PathBuf`          | Filesystem root. The field is reserved. Codegen ignores it. |
| `file`       | `String`           | The file being generated.                                   |
| `source_map` | `SourceMapOptions` | The source-map inputs and outputs requested for the step.   |

## `Generator::generate`

Generates code from the fixed AST and composes the AST's input source map into the produced source map.

The builtin generator always returns a source map. The pipeline applies the resolved output source-map mode (`Inline`, `External`, or `Both`). `Generator::generate` does not apply it.

`CodeResult` is `{ code: String, map: Option<SourceMap> }`.

## Example

```rust
use std::path::PathBuf;

use telarel::{
    parse, AstResult, CodeResult, Generator, GeneratorOptions, ParseOptions,
    SourceMapOptions,
};

let parsed: AstResult = parse(
    String::from("const x: number = 1;"),
    ParseOptions::default(),
    vec![],
).await?;

let result: CodeResult = Generator::new(
    &parsed.ast,
    GeneratorOptions {
        cwd: PathBuf::from("."),
        file: String::from("index.ts"),
        source_map: SourceMapOptions::default(),
    },
)
.generate()?;
```
