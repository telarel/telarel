---
title: Generator
description: A builtin generator over a borrowed AST and fixed options.
---

```rust
pub struct Generator<'a> { /* private fields */ }

impl<'a> Generator<'a> {
    pub fn new(ast: &'a Ast, options: GeneratorOptions) -> Self;

    pub fn generate(self) -> Result<CodeResult, CompileError>;
}
```

The pipeline uses `Generator` as the builtin generator and terminal fallback after every `generate` hook defers. It never runs the plugin chain. When plugins should be able to replace the generated result, use [`generate`](/apis/rust/generate).

## `Generator::new`

Creates a generator over `ast` and its resolved `GeneratorOptions`.

`Generator::new` borrows the AST because hook arguments are read-only.

### `GeneratorOptions`

Every field is required. In a `generate` hook, the stage options are available as `args.options`; their `source_map` carries no input or output request.

| Field        | Type               | Description                                      |
| ------------ | ------------------ | ------------------------------------------------ |
| `cwd`        | `PathBuf`          | Filesystem root used to resolve the source file. |
| `file`       | `String`           | The file being generated.                        |
| `source_map` | `SourceMapOptions` | Source-map request for the step.                 |

`cwd` anchors resolution of `file`. A relative input-map `path` resolves against the source file's directory; absolute paths are used as-is.

## `Generator::generate`

Generates code from the fixed AST. It resolves `source_map.input` against the AST source text, `cwd`, and `file`, then composes the resolved input map into the produced source map. An explicit request wins over the AST's own input map when it resolves to a map. If the request is `Inline` or `Auto` and finds no map, the AST's own map is kept. An `External` request that cannot read its map rejects.

The builtin generator always returns a source map. `Generator::generate` applies `source_map.input` but not `source_map.output`. Output delivery remains a pipeline concern: the pipeline applies the resolved output source-map mode (`Inline`, `External`, or `Both`) after the winning result.

`CodeResult` is `{ code: String, map: Option<SourceMap> }`.

## Example

```rust
use std::path::PathBuf;

use telarel::{
    parse, AstResult, CodeResult, Generator, GeneratorOptions, ParseOptions,
    SourceMapOptions,
};

let parsed: AstResult = parse(
    String::from("const x: number = 1;"),
    ParseOptions::default(),
    vec![],
).await?;

let result: CodeResult = Generator::new(
    &parsed.ast,
    GeneratorOptions {
        cwd: PathBuf::from("."),
        file: String::from("index.ts"),
        source_map: SourceMapOptions::default(),
    },
)
.generate()?;
```
