title: Generator
description: A builtin generator over a borrowed AST and fixed options.

```rust
pub struct Generator<'a> { /* private fields */ }

impl<'a> Generator<'a> {
    pub fn new(ast: &'a Ast, options: ResolvedGeneratorOptions) -> Self;

    pub fn generate(self) -> Result<CodeResult, CompileError>;
}
```

The pipeline uses `Generator` as the builtin generator and terminal fallback after every `generate` hook defers. It never runs the plugin chain. When plugins should be able to replace the generated result, use [`generate`](/apis/rust/generate).

## `Generator::new`

Creates a generator over `ast` and its resolved `ResolvedGeneratorOptions`.

`Generator::new` borrows the AST because hook arguments are read-only.

### `ResolvedGeneratorOptions`

Every field is required. This is the resolved type. To request the values, set the `generator` group on `GenerateOptions`, `CompileOptions`, or `CompileFromAstOptions`, or return it from an `options` hook. In a `generate` hook, the same value is available as `args.options`. Its `source_map` carries no input or output request.

| Field          | Type                | Description                                                             |
| -------------- | ------------------- | ----------------------------------------------------------------------- |
| `cwd`          | `PathBuf`           | Working directory used to resolve `file` and a relative input-map path. |
| `file`         | `String`            | The file being generated.                                               |
| `source_map`   | `SourceMapOptions`  | Source-map request for the step.                                        |
| `single_quote` | `bool`              | Whether string literals use single quotes.                              |
| `ascii_only`   | `bool`              | Whether non-ASCII characters are escaped.                               |
| `indent_style` | `IndentStyle`       | The resolved indentation style.                                         |
| `indent_width` | `usize`             | The resolved indentation width.                                         |
| `comments`     | `bool`              | Whether any comment category is printed.                                |
| `minify`       | `bool`              | Whether generated code is minified.                                     |
| `oxc`          | `OxcCodegenOptions` | The full effective options for the raw oxc codegen.                     |

`cwd` anchors resolution of `file`. A relative input-map `path` resolves against the source file's directory; absolute paths are used as-is.

`file` is recorded as `map.file`. `ResolvedGeneratorOptions` has no separate output name, so `file` also names the source when there is no input map.

`oxc` is the full effective object after the three [option layers](/apis#option-layering) apply. It is not the requested partial patch. Telarel owns `source_map_path`. See [generator options](/apis#generator-options).

## `Generator::generate`

Generates code from the fixed AST. It resolves `source_map.input` against the AST source text, `cwd`, and `file`, then composes the resolved input map into the produced source map. An explicit request wins over the AST's own input map when it resolves to a map. If the request is `Inline` or `Auto` and finds no map, the AST's own map is kept. An `External` request that cannot read its map rejects.

The builtin generator always returns a source map. `Generator::generate` applies `source_map.input` but not `source_map.output`. Output delivery remains a pipeline concern: the pipeline applies the resolved output source-map mode (`Inline`, `External`, or `Both`) after the winning result.

`CodeResult` is `{ code: String, map: Option<SourceMap> }`.

## Example

```rust
use std::path::PathBuf;

use telarel::{
    parse, AstResult, CodeResult, Generator, IndentStyle, ParseOptions,
    ResolvedGeneratorOptions, ResolvedGeneratorStageOptions, SourceMapOptions,
};

let parsed: AstResult = parse(
    String::from("const x: number = 1;"),
    ParseOptions::default(),
    vec![],
).await?;

let result: CodeResult = Generator::new(
    &parsed.ast,
    ResolvedGeneratorOptions {
        cwd: PathBuf::from("."),
        file: String::from("index.ts"),
        source_map: SourceMapOptions::default(),
        single_quote: false,
        ascii_only: false,
        indent_style: IndentStyle::Space,
        indent_width: 2,
        comments: true,
        minify: false,
        oxc: ResolvedGeneratorStageOptions::default().oxc,
    },
)
.generate()?;
```
