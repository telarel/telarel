---
title: generate
description: Generate code from an AST.
---

```rust
pub async fn generate(
    ast: Ast,
    options: GenerateOptions,
    plugins: Vec<SharedPluginable>,
) -> Result<CodeResult, CompileError>
```

Generates code from `ast`.

The builtin generator is the terminal fallback after every `generate` hook defers. The pipeline applies the resolved output source-map mode to the winning result.

An explicit input source-map request wins over the AST's own input map when it resolves to a map. If the request is `Inline` or `Auto` and finds no map, the AST's own map is kept. An `External` request that cannot read its map rejects.

The `generate` hook's generator options carry an empty source-map request. Input resolution happens before the hook; output delivery happens after the winning result.

## Parameters

| Name      | Type                    | Description               |
| --------- | ----------------------- | ------------------------- |
| `ast`     | `Ast`                   | The AST to generate from. |
| `options` | `GenerateOptions`       | The generate options.     |
| `plugins` | `Vec<SharedPluginable>` | The plugins to run.       |

### `GenerateOptions`

Every field is optional. The pipeline resolves each field against defaults before use.

| Field        | Type                       | Default             | Description                                                                                                             |
| ------------ | -------------------------- | ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `cwd`        | `Option<PathBuf>`          | process working dir | Filesystem root used to resolve relative paths.                                                                         |
| `file`       | `Option<String>`           | `index.ts`          | The file being generated. It is used for option resolution and source-map defaults. It does not change the AST grammar. |
| `language`   | `Option<Language>`         | AST language        | The grammar recorded in the resolved step options and visible to plugins. Builtin generation uses the AST grammar.      |
| `output`     | `Option<OutputOptions>`    | unset               | [Output code configuration](/apis#output-options).                                                                      |
| `source_map` | `Option<SourceMapOptions>` | off                 | [Source-map inputs and outputs](/apis#source-maps) requested for the step.                                              |

The pipeline resolves `language` into the step options. An explicit value wins. Otherwise, the AST grammar wins. The explicit value is visible to the `options` hook. The resolved value is visible to `start` and later hooks through the resolved options and `PluginContext.module`.

Builtin code generation does not use the resolved value. It emits from the AST's own `Program.source_type`. Module kind remains owned by `Program.source_type`. An options hook can still return `source_type`; a value other than `Unambiguous` replaces `Program.source_type` before generation. There is no `GenerateOptions.source_type`.

## Returns

`Result<CodeResult, CompileError>`, where `CodeResult` is `{ code: String, map: Option<SourceMap> }`.

## Example

```rust
use telarel::{generate, parse, GenerateOptions, ParseOptions, AstResult, CodeResult};

let parsed: AstResult = parse(
    String::from("const x: number = 1;"),
    ParseOptions::default(),
    vec![],
).await?;

let result: CodeResult = generate(parsed.ast, GenerateOptions::default(), vec![]).await?;

println!("{}", result.code);
```
