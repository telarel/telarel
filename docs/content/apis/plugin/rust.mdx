The `telarel` crate re-exports the plugin interface from `telarel_plugin`. A Rust plugin implements the `Plugin` trait. `Plugin::new_shared` wraps it into a shared, object-safe handle.

For the hook contract shared by both languages, see the [Plugin API](/apis/plugin).

## The `Plugin` trait

```rust
pub trait Plugin: Any + Debug + Send + Sync + 'static {
    fn new_shared(plugin: Self) -> SharedPluginable
    where
        Self: Sized;

    fn name(&self) -> Cow<'static, str>;

    fn register_hook_usage(&self) -> HookUsage;

    // ... one method per hook, each defaulting to a no-op ...
}
```

- `name` returns the plugin name.
- `register_hook_usage` declares which hooks the plugin implements. `parse`, `prepare`, `transform`, `finalize`, and `generate` run only when declared. `options` runs once per distinct instance. `start` and `end` run on every settled entry, duplicates included. A settled entry is an entry in the plugin list after the `options` stage.
- `new_shared` wraps a sized plugin into a `SharedPluginable` (`Arc<dyn Pluginable>`). The handle, not the name, is the `options` identity. `Pluginable` is the object-safe mirror of the trait. Every `Plugin` implements it.

Every hook has a default implementation that does nothing, so a plugin only writes the hooks it needs.

### `HookUsage`

`HookUsage` is a bit flag set with one flag for each hook:

```rust
use telarel::HookUsage;

let usage: HookUsage = HookUsage::Prepare | HookUsage::End;
```

The flags are `Options`, `Start`, `Parse`, `Prepare`, `Transform`, `Finalize`, `Generate`, and `End`.

## Hooks

Each hook returns an `impl Future`, so you can write its body as an `async` block. The context borrows the pipeline state. The hook future resolves to its return type.

| Hook        | Arguments                              | Return            |
| ----------- | -------------------------------------- | ----------------- |
| `options`   | `&CommonPluginContext`, `&OptionsArgs` | `OptionsReturn`   |
| `start`     | `&PluginContext`, `&StartArgs`         | `NotifyReturn`    |
| `parse`     | `&PluginContext`, `ParseArgs`          | `ParseReturn`     |
| `prepare`   | `&PluginContext`, `PrepareArgs`        | `NotifyReturn`    |
| `transform` | `&PluginContext`, `TransformArgs`      | `TransformReturn` |
| `finalize`  | `&PluginContext`, `FinalizeArgs`       | `NotifyReturn`    |
| `generate`  | `&PluginContext`, `GenerateArgs`       | `GenerateReturn`  |
| `end`       | `&PluginContext`, `&EndArgs`           | `NotifyReturn`    |

### Arguments

| Type            | Fields                                                         |
| --------------- | -------------------------------------------------------------- |
| `OptionsArgs`   | `options: ResolvableOptions`, `plugins: Vec<SharedPluginable>` |
| `StartArgs`     | `options: ResolvedOptions`                                     |
| `ParseArgs`     | `code: &str`, `options: &ParserOptions`                        |
| `PrepareArgs`   | `ast: &Ast`                                                    |
| `TransformArgs` | `ast: Ast` (owned)                                             |
| `FinalizeArgs`  | `ast: &Ast`                                                    |
| `GenerateArgs`  | `ast: &Ast`, `options: &GeneratorOptions`                      |
| `EndArgs`       | `error: Option<CompileError>`                                  |

Every entry point uses the options bag, which always uses `source_map`. `parse` and `rewrite` expose a flat `input_source_map` at the entry point. The pipeline normalizes it to `source_map.input` before the `options` hook runs.

Those AST-producing entry points ignore `source_map.output` and `output`. A stage-agnostic plugin can set them for every stage without failing.

The pipeline uses a `parse` hook replacement exactly as the hook returns it. Its own `Ast` / `Program.source_type` provides the grammar for later stages and code regeneration. The pipeline passes `ParserOptions` to the hook.

The driver applies these options only to the builtin parser that runs when every hook defers, which means no hook returns a replacement. The builtin is the compiler's own parser or generator. The JavaScript binding differs: it rebuilds a parse replacement with the grammar of the parser options.

`TransformArgs` owns a cheap [Ast](/apis/rust/Ast) handle. `Ast::clone` is O(1). `Ast::with_mut` copies the arena on write when the driver still holds the carried AST. The carried AST is the AST that `transform` passes from plugin to plugin. `TransformArgs` is `Clone`, not `Copy`. Returning `None` leaves the driver's AST untouched.

`with_mut` can rewrite the tree. Changing the source text requires a new [Ast](/apis/rust/Ast) that the hook returns. Debug builds assert that `Program::source_text` still matches `Ast::source`.

`TransformOutput` is the value that a `transform` hook returns to replace the carried AST. It wraps the new owned `ast`.

### Returns

Every fallible hook returns `Result<_, PluginError>`. `NotifyReturn` is `Result<(), PluginError>`. The stages that return a value return `Option` inside the result. `None` means "no change".

| Type              | Definition                                     |
| ----------------- | ---------------------------------------------- |
| `OptionsReturn`   | `Result<Option<OptionsArgs>, PluginError>`     |
| `NotifyReturn`    | `Result<(), PluginError>`                      |
| `ParseReturn`     | `Result<Option<AstResult>, PluginError>`       |
| `TransformReturn` | `Result<Option<TransformOutput>, PluginError>` |
| `GenerateReturn`  | `Result<Option<CodeResult>, PluginError>`      |

Returning `Some` from `options` replaces the whole bag. Omitted fields take their default values. Duplicates and the depth guard follow the [shared fixpoint rules](/apis/plugin#hook-semantics).

### Errors

A hook reports failure with [PluginError](/apis/rust/PluginError). The error reaches the entry point as a [CompileError](/apis/rust/CompileError) with its message and attached source unchanged.

## Ordering

Each Rust hook exposes a `<hook>_meta` method that returns `Option<PluginHookMeta>`. All these methods default to `None`. `PluginOrder` is `Pre` or `Post`.

```rust
use telarel::{PluginHookMeta, PluginOrder};

fn transform_meta(&self) -> Option<PluginHookMeta> {
    Some(PluginHookMeta { order: Some(PluginOrder::Pre) })
}
```

## Context

- `options` receives `CommonPluginContext`, which has no fields.
- Every later hook receives `PluginContext`:

| Field    | Type         | Description                                     |
| -------- | ------------ | ----------------------------------------------- |
| `cwd`    | `&Path`      | Filesystem root used to resolve relative paths. |
| `module` | `ModuleInfo` | Module being compiled.                          |

`ModuleInfo` holds `file: &str` (the file being compiled), `language: Language`, and `source_type: SourceType`.

## Passing plugins

Wrap each plugin in `Plugin::new_shared` and pass the list to any entry point.

```rust
use telarel::{CodeResult, CompileOptions, Plugin, SharedPluginable, compile};

let plugins: Vec<SharedPluginable> = vec![
    Plugin::new_shared(TracePlugin),
    Plugin::new_shared(ReplaceRootPlugin),
];

let result: CodeResult = compile(
    String::from("const x: number = 1;"),
    CompileOptions::default(),
    plugins,
)
.await?;
```

## Example

The example plugin rewrites the module specifier `react` to `preact/compat` in `transform`. The hook owns a cheap AST handle and mutates it through `Ast::with_mut`, which copies the arena on write. The hook returns the mutated AST as `TransformOutput`:

<PeekCode>

```rust
use std::borrow::Cow;
use std::future::Future;

use telarel::allocator::Allocator;
use telarel::ast::ast::{ImportDeclaration, Program};
use telarel::ast_visit::VisitMut;
use telarel::ast_visit::walk_mut;
use telarel::str::Str;
use telarel::{
    Ast, HookUsage, Plugin, PluginContext, TransformArgs, TransformOutput,
    TransformReturn,
};

const FROM: &str = "react";

const TO: &str = "preact/compat";

struct ImportRewriter<'x> {
    allocator: &'x Allocator,
}

impl<'x> VisitMut<'x> for ImportRewriter<'x> {
    fn visit_import_declaration(
        &mut self,
        declaration: &mut ImportDeclaration<'x>,
    ) {
        if declaration.source.value.as_str() == FROM {
            declaration.source.value = Str::from_str_in(TO, &self.allocator);
        }
    }
}

#[derive(Debug)]
struct ImportRewritePlugin;

impl Plugin for ImportRewritePlugin {
    fn name(&self) -> Cow<'static, str> {
        "import-rewrite".into()
    }

    fn register_hook_usage(&self) -> HookUsage {
        HookUsage::Transform
    }

    fn transform<'a>(
        &'a self,
        _ctx: &'a PluginContext<'_>,
        args: TransformArgs,
    ) -> impl Future<Output = TransformReturn> + Send + 'a {
        async move {
            let mut ast: Ast = args.ast;

            ast.with_mut(|allocator: &Allocator, program: &mut Program<'_>| {
                let mut rewriter: ImportRewriter<'_> =
                    ImportRewriter { allocator };

                walk_mut::walk_program(&mut rewriter, program);
            });

            Ok(Some(TransformOutput { ast }))
        }
    }
}
```
