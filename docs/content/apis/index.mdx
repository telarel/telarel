## Shared pipeline

Telarel exposes almost same compiler pipeline through a JavaScript package and a Rust crate.

- **JavaScript API** — the `telarel` package, with TypeScript types. Backed by a NAPI binding to the Rust core.
- **Rust API** — the `telarel` crate, re-exporting the public facing API.

Both expose the same entry functions. Each call takes the source (text or an owned AST), an options value, and a list of plugins, and returns either an AST result or a code result with an optional source map.

Both also share the same plugin interface. See the [Plugin API](/apis/plugin) for the hook semantics, and the [JavaScript](/apis/plugin/javascript) and [Rust](/apis/plugin/rust) pages for the language-specific surface.

## Options

Every function accepts the options relevant to the stages it runs. The options are optional; omitted values are resolved against defaults before the pipeline starts. See each function page for the exact fields it accepts.

## Results

- **AST result** — the parsed or rewritten AST together with the source text its spans anchor to, and an optional source map.
- **Code result** — the generated code and an optional source map.

See the individual function pages for the exact shapes.
