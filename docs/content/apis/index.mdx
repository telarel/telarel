## Shared pipeline

Telarel exposes almost the same compiler pipeline through a JavaScript package and a Rust crate.

- **JavaScript API**: the `telarel` package, with TypeScript types. It uses a NAPI binding to the Rust core.
- **Rust API**: the `telarel` crate, which re-exports the public-facing API.

Both expose the same pipeline entry points. Each call takes a source text or an owned AST, an options value, and a list of plugins. It returns an AST result or a code result with an optional source map.

Both also expose builtin constructors that bypass the plugin chain: [`createParser`](/apis/javascript/createParser) and [`createGenerator`](/apis/javascript/createGenerator) in JavaScript, and [`Parser`](/apis/rust/Parser) and [`Generator`](/apis/rust/Generator) in Rust. Use them inside hooks to delegate to the builtin stage, or directly when plugins are not needed.

They also share the same plugin interface. See the [Plugin API](/apis/plugin) for the hook semantics, and the [JavaScript](/apis/plugin/javascript) and [Rust](/apis/plugin/rust) pages for the language-specific surface.

## Options

Every pipeline entry point accepts the options for the stages it runs. You can omit any option. The compiler resolves omitted values against defaults before the stages run. Builtin constructors instead take fully resolved options. See each page for the exact fields.

## Results

- **AST result**: the parsed or rewritten AST, the source text its spans anchor to, and an optional source map.
- **Code result**: the generated code and an optional source map.

See the individual function pages for the exact shapes.

## Types and errors

| Type           | Description                                                                      | Reference                                                                    |
| -------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `Ast`          | A program, its source text, language metadata, and an optional input source map. | [JavaScript](/apis/javascript/Ast), [Rust](/apis/rust/Ast)                   |
| `ErrorSource`  | A source location made of a file, its source text, and a span within it.         | [JavaScript](/apis/javascript/ErrorSource), [Rust](/apis/rust/ErrorSource)   |
| `PluginError`  | An error reported by a plugin hook, with an optional source location.            | [JavaScript](/apis/javascript/PluginError), [Rust](/apis/rust/PluginError)   |
| `CompileError` | An entry-point failure with an optional source location.                         | [JavaScript](/apis/javascript/CompileError), [Rust](/apis/rust/CompileError) |
