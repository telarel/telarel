---
title: generate
description: Generate code from an AST.
---

```ts
function generate(ast: Ast, options?: GenerateOptions): Promise<CodeResult>;

function generate(
    program: Program,
    code: string,
    options?: GenerateOptions,
): Promise<CodeResult>;
```

Generates code from an AST with plugins, in memory.

The AST's own input map wins. Otherwise, the pipeline attaches the requested input map before generation. The builtin generator is the terminal fallback when every `generate` hook defers. The pipeline applies the resolved output source-map mode to the winning result.

## Parameters

The function accepts either an [Ast](/apis/javascript/Ast) instance or a bare ESTree `Program` with its source text.

| Name      | Type              | Description                |
| --------- | ----------------- | -------------------------- |
| `ast`     | `Ast`             | An AST instance.           |
| `options` | `GenerateOptions` | Optional generate options. |

| Name      | Type              | Description                                                             |
| --------- | ----------------- | ----------------------------------------------------------------------- |
| `program` | `Program`         | A bare ESTree program.                                                  |
| `code`    | `string`          | The source text the program's spans anchor to. Required with `program`. |
| `options` | `GenerateOptions` | Optional generate options.                                              |

### `GenerateOptions`

| Field       | Type               | Default          | Description                                                                       |
| ----------- | ------------------ | ---------------- | --------------------------------------------------------------------------------- |
| `cwd`       | `string`           | `process.cwd()`  | Current working directory.                                                        |
| `file`      | `string`           | `index.ts`       | The file being generated. Its extension is the final fallback for the grammar.    |
| `language`  | `Language`         | inferred         | The grammar to generate with. Overrides the AST language and extension inference. |
| `output`    | `OutputOptions`    | `{ file: file }` | Output code configuration. `output.file` derives the default source-map URL.      |
| `sourceMap` | `SourceMapOptions` | off              | The source-map inputs and outputs requested for the step.                         |
| `plugins`   | `PluginOption[]`   | `[]`             | The plugins to run.                                                               |

The grammar precedence is `options.language > Ast.language > file extension`.

`ast.program.sourceType` owns the module kind. An options hook can still return `sourceType`; a value other than `"unambiguous"` replaces `ast.program.sourceType` before generation. `generate` has no `sourceType` option.

The pipeline treats an empty `output.file` or `sourceMap.output.url` as unset, the same as absent.

## Returns

`Promise<CodeResult>`:

| Field  | Type                | Description                                                          |
| ------ | ------------------- | -------------------------------------------------------------------- |
| `code` | `string`            | The generated code.                                                  |
| `map`  | `SourceMap \| null` | The source map for the generated code, or `null` when no map exists. |

## Example

```ts
import type { AstResult, CodeResult } from "telarel";

import { parse, generate } from "telarel";

const { ast }: AstResult = await parse("const x: number = 1;");

const result: CodeResult = await generate(ast);
```
