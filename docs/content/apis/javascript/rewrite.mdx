---
title: rewrite
description: Rewrite an AST with plugins.
---

```ts
function rewrite(ast: Ast, options?: RewriteOptions): Promise<AstResult>;

function rewrite(
    program: Program,
    code: string,
    options?: RewriteOptions,
): Promise<AstResult>;
```

Rewrites an AST with plugins, in memory.

The AST's own input map wins. Otherwise, the pipeline attaches the requested input map before the stages run.

## Parameters

The function accepts either an [Ast](/apis/javascript/Ast) instance or a bare ESTree `Program` with its source text.

| Name      | Type             | Description               |
| --------- | ---------------- | ------------------------- |
| `ast`     | `Ast`            | An AST instance.          |
| `options` | `RewriteOptions` | Optional rewrite options. |

| Name      | Type             | Description                                                             |
| --------- | ---------------- | ----------------------------------------------------------------------- |
| `program` | `Program`        | A bare ESTree program.                                                  |
| `code`    | `string`         | The source text the program's spans anchor to. Required with `program`. |
| `options` | `RewriteOptions` | Optional rewrite options.                                               |

### `RewriteOptions`

| Field            | Type             | Default                    | Description                                |
| ---------------- | ---------------- | -------------------------- | ------------------------------------------ |
| `cwd`            | `string`         | `process.cwd()`            | Current working directory.                 |
| `file`           | `string`         | `index.ts`                 | The file being rewritten.                  |
| `language`       | `Language`       | inferred                   | The grammar of the code.                   |
| `sourceType`     | `SourceType`     | AST module kind, then file | The module kind of the code.               |
| `inputSourceMap` | `InputSourceMap` | off                        | The input source-map request for the step. |
| `plugins`        | `PluginOption[]` | `[]`                       | The plugins to run.                        |

The grammar comes from `options.language`, then the AST language, then the file extension.

The module kind comes from a concrete `sourceType`, then the AST module kind, then the file extension. `"unambiguous"` requests inference. A concrete `sourceType` replaces the AST module kind before the stages run.

`InputSourceMap` is a `SourceMap` value, a literal input mode (`"inline"`, `"external"`, or `"auto"`), or `{ mode, path? }`. In the options form, `mode` accepts a `SourceMap` value or a literal input mode.

`rewrite` produces an AST, so it has no output source map. The shared plugin options bag presents this request as `sourceMap.input`. `rewrite` ignores a plugin-set `sourceMap.output` or top-level `output`.

## Returns

`Promise<AstResult>`, where `AstResult` is `{ ast: Ast }`. The returned `Ast` carries the resolved language.

## Example

```ts
import type { AstResult } from "telarel";

import { parse, rewrite } from "telarel";

const { ast }: AstResult = await parse("const x: number = 1;");

const result: AstResult = await rewrite(ast);
```
