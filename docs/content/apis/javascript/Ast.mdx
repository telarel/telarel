---
title: Ast
description: An AST with its source text, optional language metadata and source map, and mutable program access.
---

`Ast` carries an Oxc-backed `Program`, the source text its spans anchor to, optional language metadata, and an optional incremental source map. Every hook that takes an AST receives an `Ast`.

```ts
type AstOptions = {
    program: Program;
    source: string;
    language?: Language;
    map?: SourceMap;
};

class Ast {
    constructor(options: AstOptions);

    get program(): DeepReadonly<Program>;
    get source(): Readonly<string>;
    get language(): Language | void;
    get sourceType(): SourceType;
    get map(): DeepReadonly<SourceMap> | null;

    mutate<Result extends void | Promise<void>>(
        fn: (program: Program) => Result,
    ): Result;
}
```

## Constructor

| Field      | Type        | Description                                                                                                                                          |
| ---------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `program`  | `Program`   | The ESTree program.                                                                                                                                  |
| `source`   | `string`    | The source text the program's spans anchor to.                                                                                                       |
| `language` | `Language`  | Optional grammar of the program. When you omit it for `new Ast({ program, source })`, ESTree cannot carry grammar, so the grammar stays `undefined`. |
| `map`      | `SourceMap` | Optional incremental source map. When no map is available, omit `map`.                                                                               |

## Members

| Member       | Type                              | Description                                                                                                  |
| ------------ | --------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `program`    | `DeepReadonly<Program>`           | A deeply read-only view of the program. Use `mutate` to change it.                                           |
| `source`     | `string`                          | The source text the program's spans anchor to.                                                               |
| `language`   | `Language \| void`                | The grammar of the program, or `undefined` when unknown. `parse`, `rewrite`, and `createParser` populate it. |
| `sourceType` | `SourceType`                      | The module kind. It reads through `program.sourceType`. Values are `"script" \| "module" \| "commonjs"`.     |
| `map`        | `DeepReadonly<SourceMap> \| null` | The incremental source map, or `null` when the AST carries none.                                             |
| `mutate`     | `(fn) => Result`                  | Runs `fn` with mutable access to the program and returns its result.                                         |

`sourceType` reads through `ast.program.sourceType` and never returns `"unambiguous"`. There is no stored source-type field, so changes that `Ast.mutate` makes appear immediately.

When an entry point resolves a grammar, `options.language` wins over `Ast.language`. `Ast.language` wins over the `file` extension.

The `program` getter has type `DeepReadonly<Program>`, so callers cannot change nested nodes or arrays through it.

`mutate` returns `void` for a synchronous callback and `Promise<void>` for an asynchronous one. The return value matches the callback, so `await ast.mutate(fn)` works in both cases.

## Comments

`Program` is the Oxc program plus optional comments:

```ts
type Program = OxcProgram & { comments?: Comment[] };

type Comment = {
    type: "Line" | "Block";
    value: string;
    start: number;
    end: number;
    attachedTo?: number;
    position?: "leading" | "trailing";
    newlines?: { leading: boolean; trailing: boolean };
    content?: CommentContent;
};
```

`start`, `end`, and `attachedTo` are UTF-16 code-unit offsets. `start` and `end` must be UTF-16 boundaries. Non-boundaries, mid-surrogate offsets, reversed spans, and missing spans reject. `type` must be `"Line"` or `"Block"` and must match the source delimiter.

The compiler ignores an invalid or stale `attachedTo` and re-derives it from a codegen anchor instead of rejecting it. Absent `comments` and `comments: []` both mean no comments. A present non-array `comments` value rejects. The compiler derives `value` from the source text and ignores it on input.

Comments survive AST round-trips. An AST that `parse` or `transform` returns owns its comments. Returning an AST without comments drops them.

`parse` may return comments that report oxc's parser position. Inline comments may report `"trailing"`. The compiler normalizes inbound `position` to `"leading"`. Oxc codegen emits only leading comments, so placement depends on codegen.

The `content` label is one of `"none"`, `"legal"`, `"jsdoc"`, `"jsdoc-legal"`, `"pure"`, `"pure-not-applied"`, `"no-side-effects"`, `"no-side-effects-not-applied"`, `"webpack"`, `"vite"`, `"turbopack"`, `"coverage-ignore"`, `"coverage-ignore-file"`, and `"property-key"`. An unknown `position` or `content` label rejects. When the compiler rebuilds a comment, an applied `pure` or `no-side-effects` comment keeps its text. The rebuild demotes it to `content: "none"`.

`telarel` and `telarel/ast` export `Comment`, `CommentContent`, `CommentPosition`, `CommentType`, `OxcProgram`, and `Program`.

## Mutation

Only the `transform` hook passes mutations to later stages. Mutate `args.ast` and return `{ ast: args.ast }` to replace the compiler's AST for the rest of the chain. Returning nothing discards the mutation.

The `prepare`, `finalize`, and `generate` hooks receive a snapshot of the compiler's AST. Mutating that snapshot changes only the local instance and does not alter the compiler's AST. A `generate` hook can pass a mutated AST to [createGenerator](/apis/javascript/createGenerator) to generate from it.

## Example

```ts
import type { AstResult } from "telarel";

import { parse } from "telarel";

const { ast }: AstResult = await parse("const x: number = 1;");

ast.mutate((program): void => {
    program.body.length = 0;
});
```
