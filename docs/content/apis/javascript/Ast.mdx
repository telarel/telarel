---
title: Ast
description: An AST with its source text, optional language metadata and source map, and mutable program access.
---

`Ast` carries an Oxc-backed `Program`, the source text its spans anchor to, optional language metadata, and an optional incremental source map. Every AST-bearing hook receives an `Ast`.

```ts
type AstOptions = {
    program: Program;
    source: string;
    language?: Language;
    map?: SourceMap;
};

class Ast {
    constructor(options: AstOptions);

    get program(): DeepReadonly<Program>;
    get source(): Readonly<string>;
    get language(): Language | void;
    get sourceType(): SourceType;
    get map(): DeepReadonly<SourceMap> | null;

    mutate<Result extends void | Promise<void>>(
        fn: (program: Program) => Result,
    ): Result;
}
```

## Constructor

| Field      | Type        | Description                                                                                                                     |
| ---------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `program`  | `Program`   | The ESTree program.                                                                                                             |
| `source`   | `string`    | The source text the program's spans anchor to.                                                                                  |
| `language` | `Language`  | Optional grammar of the program. Omit for `new Ast({ program, source })`: ESTree cannot carry grammar, so it stays `undefined`. |
| `map`      | `SourceMap` | Optional incremental source map. Omit when unavailable.                                                                         |

## Members

| Member       | Type                              | Description                                                                                                   |
| ------------ | --------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `program`    | `DeepReadonly<Program>`           | A deeply read-only view of the program. Use `mutate` to change it.                                            |
| `source`     | `string`                          | The source text the program's spans anchor to.                                                                |
| `language`   | `Language \| void`                | The grammar of the program, or `undefined` when unknown. Populated by `parse`, `rewrite`, and `createParser`. |
| `sourceType` | `SourceType`                      | The module kind, read through from `program.sourceType`. Values are `"script" \| "module" \| "commonjs"`.     |
| `map`        | `DeepReadonly<SourceMap> \| null` | The incremental source map, or `null` when the AST carries none.                                              |
| `mutate`     | `(fn) => Result`                  | Runs `fn` with mutable access to the program and returns its result.                                          |

`sourceType` is a read-through of `ast.program.sourceType`; it never returns `"unambiguous"`. There is no stored source-type field, so changes made through `Ast.mutate` are reflected immediately.

When an entry point resolves a grammar, explicit `options.language` wins over `Ast.language`, which wins over the `file` extension.

The `program` getter is typed as `DeepReadonly<Program>`, so nested nodes and arrays cannot be changed through it.

`mutate` returns `void` for a synchronous callback and `Promise<void>` for an asynchronous one. The returned value matches the callback, so `await ast.mutate(fn)` works in both cases.

## Comments

`Program` is the Oxc program plus optional comments:

```ts
type Program = OxcProgram & { comments?: Comment[] };

type Comment = {
    type: "Line" | "Block";
    value: string;
    start: number;
    end: number;
    attachedTo?: number;
    position?: "leading" | "trailing";
    newlines?: { leading: boolean; trailing: boolean };
    content?: CommentContent;
};
```

`start`, `end`, and `attachedTo` are UTF-16 code-unit offsets. `start` and `end` must be UTF-16 boundaries; non-boundaries, mid-surrogate offsets, reversed spans, and missing spans reject. `type` must be `"Line"` or `"Block"` and match the source delimiter. An invalid or stale `attachedTo` is ignored and re-derived from a codegen anchor rather than rejected. Absent `comments` and `comments: []` both mean no comments; a present non-array `comments` value rejects. `value` is derived from the source text and ignored on input.

Comments survive AST round-trips. A returned parse or transform AST owns its comments, and returning an AST without comments drops them.

Comments carried out of `parse` may report oxc's parser position (`"trailing"` for inline comments). Inbound `position` is normalized to `"leading"`; oxc codegen emits only leading comments, so placement is codegen-defined.

The `content` label is one of `"none"`, `"legal"`, `"jsdoc"`, `"jsdoc-legal"`, `"pure"`, `"pure-not-applied"`, `"no-side-effects"`, `"no-side-effects-not-applied"`, `"webpack"`, `"vite"`, `"turbopack"`, `"coverage-ignore"`, `"coverage-ignore-file"`, and `"property-key"`. An unknown `position` or `content` label rejects. Applied `pure` or `no-side-effects` comments keep their text but are demoted to `content: "none"` when rebuilt.

`Comment`, `CommentContent`, `CommentPosition`, `CommentType`, `OxcProgram`, and `Program` are exported from both `telarel` and `telarel/ast`.

## Mutation

Only the `transform` hook carries mutations forward: mutate `args.ast` and return `{ ast: args.ast }` to replace the compiler's AST for the rest of the chain. Returning nothing discards the mutation.

The `prepare`, `finalize`, and `generate` hooks receive a snapshot of the compiler's AST. Mutating that snapshot changes only the local instance and does not alter the compiler's AST. A `generate` hook can pass a mutated AST to [createGenerator](/apis/javascript/createGenerator) to generate from it.

## Example

```ts
import type { AstResult } from "telarel";

import { parse } from "telarel";

const { ast }: AstResult = await parse("const x: number = 1;");

ast.mutate((program): void => {
    program.body.length = 0;
});
```
