---
title: compileFromAst
description: Compile an existing AST through rewrite and generation.
---

```ts
function compileFromAst(
    ast: Ast,
    options?: CompileFromAstOptions,
): Promise<CodeResult>;

function compileFromAst(
    program: Program,
    code: string,
    options?: CompileFromAstOptions,
): Promise<CodeResult>;
```

Compiles an existing AST through rewrite and generation, with plugins, in memory.

## Parameters

The function accepts either an [Ast](/apis/javascript/Ast) instance or a bare ESTree `Program` with its source text.

| Name      | Type                    | Description               |
| --------- | ----------------------- | ------------------------- |
| `ast`     | `Ast`                   | An AST instance.          |
| `options` | `CompileFromAstOptions` | Optional compile options. |

| Name      | Type                    | Description                                                             |
| --------- | ----------------------- | ----------------------------------------------------------------------- |
| `program` | `Program`               | A bare ESTree program.                                                  |
| `code`    | `string`                | The source text the program's spans anchor to. Required with `program`. |
| `options` | `CompileFromAstOptions` | Optional compile options.                                               |

### `CompileFromAstOptions`

| Field        | Type               | Default                    | Description                                                               |
| ------------ | ------------------ | -------------------------- | ------------------------------------------------------------------------- |
| `cwd`        | `string`           | `process.cwd()`            | Current working directory.                                                |
| `file`       | `string`           | `index.ts`                 | The file being compiled.                                                  |
| `language`   | `Language`         | inferred                   | The grammar of the code.                                                  |
| `sourceType` | `SourceType`       | AST module kind, then file | The module kind of the code.                                              |
| `output`     | `OutputOptions`    | unset                      | [Output code configuration](/apis#output-options).                        |
| `sourceMap`  | `SourceMapOptions` | off                        | [Source-map inputs and outputs](/apis#source-maps) requested for the run. |
| `plugins`    | `PluginOption[]`   | `[]`                       | The plugins to run.                                                       |

The grammar comes from `options.language`, then the AST language, then the file extension.

The module kind comes from a concrete `sourceType`, then the AST module kind, then the file extension. `"unambiguous"` requests inference. A concrete `sourceType` replaces the AST module kind before the stages run.

`compileFromAst` reads the AST language but returns only code and an optional map.

See [output file](/plugins/transform#output-file) for how the transform plugin derives `output.file`.

An explicit input source-map request wins over the AST's own input map when it resolves to a map. If the request is `inline` or `auto` and finds no map, the AST's own map is kept. An `external` request that cannot read its map rejects.

The request applies to the AST at the entry boundary. A map returned by a transform hook is the downstream result and is not replaced by the request.

## Returns

`Promise<CodeResult>`:

| Field  | Type                | Description                                                          |
| ------ | ------------------- | -------------------------------------------------------------------- |
| `code` | `string`            | The generated code.                                                  |
| `map`  | `SourceMap \| null` | The source map for the generated code, or `null` when no map exists. |

## Example

```ts
import type { AstResult, CodeResult } from "telarel";

import { compileFromAst, parse } from "telarel";

const { ast }: AstResult = await parse("const x: number = 1;");

const result: CodeResult = await compileFromAst(ast);
```
