---
title: Plugins
description: Extend the Telarel pipeline with plugins.
---

Telarel is built around plugin hooks. A plugin receives the source, the options, and the current pipeline state, and contributes to the stages it declares. Every entry point takes plugins alongside the options.

- the [Plugin API](/apis/plugin): the hook contract shared by both languages, with the [JavaScript](/apis/plugin/javascript) and [Rust](/apis/plugin/rust) surfaces
- the [Transform plugin](/plugins/transform): the builtin plugin that lowers TypeScript and modern syntax, lowers JSX when configured, and applies `define` and `inject`
